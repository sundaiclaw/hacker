# Design System References

Curated design system profiles for common Sundai MVP categories. Each defines a visual identity that the ideation phase can reference in the spec seed's Design Direction block.

Pick the system closest to the project's domain. Use the color palette, font pairing, and component guidelines as the spec's design target. The Fabro implement and polish steps will follow these values.

---

## 1. Dev Tool (Linear-inspired)

**Vibe:** Ultra-minimal, precise, focused. Dark mode default with purple accent.

**Palette:**
- Background: `#1a1a2e` (deep navy)
- Surface: `#242438` (elevated panels)
- Text Primary: `#e8e8ed` (soft white)
- Text Secondary: `#8b8b9e` (muted lavender)
- Accent: `#7c5cfc` (electric purple)

**Fonts:** Inter (body) + Inter (headings, weight 600)

**Components:**
- Cards: no border, subtle background shift, 8px radius
- Buttons: accent bg, white text, 6px radius, 8px 16px padding
- Inputs: transparent bg, 1px border `#3a3a4e`, 6px radius
- Spacing: 8px base, dense layout, minimal whitespace

**Layout:** Sidebar navigation + main content area. Data-dense, keyboard-first.

## 2. Fintech / Business Tool (Stripe-inspired)

**Vibe:** Technical yet luxurious. Light mode with purple accent and blue-tinted shadows.

**Palette:**
- Background: `#ffffff`
- Surface: `#f6f9fc` (cool white)
- Text Primary: `#0a2540` (deep navy)
- Text Secondary: `#425466` (slate)
- Accent: `#635bff` (Stripe purple)

**Fonts:** Inter (body, weight 400) + Inter (headings, weight 300 — light, confident)

**Components:**
- Cards: white bg, `1px solid #e3e8ee` border, 8px radius, blue-tinted shadow
- Buttons: accent bg, white text, 4px radius, 8px 16px padding
- Inputs: `1px solid #e3e8ee` border, focus ring accent
- Shadows: `rgba(50,50,93,0.25) 0px 2px 5px -1px, rgba(0,0,0,0.1) 0px 1px 3px -1px`

**Layout:** Centered content (max 1080px), alternating white/dark sections. Clean and spacious.

## 3. Health / Wellness

**Vibe:** Calming, trustworthy, warm. Soft greens and natural tones.

**Palette:**
- Background: `#fafaf7` (warm off-white)
- Surface: `#ffffff`
- Text Primary: `#1a2e1a` (deep forest)
- Text Secondary: `#5a6b5a` (muted sage)
- Accent: `#2d8a4e` (balanced green)

**Fonts:** DM Sans (body) + Fraunces (headings — warm serif)

**Components:**
- Cards: white bg, `1px solid #e8ede8` border, 12px radius
- Buttons: accent bg, white text, 8px radius, rounded but not pill
- Inputs: soft border, 8px radius, generous padding
- Shadows: warm-toned `rgba(26,46,26,0.06) 0px 4px 16px`

**Layout:** Single-page scroll with generous whitespace. Large hero, clear CTA. Breathing room between sections.

## 4. Creative Tool / Design Platform

**Vibe:** Bold, expressive, energetic. Vibrant colors with strong contrast.

**Palette:**
- Background: `#ffffff`
- Surface: `#f8f7ff` (subtle violet tint)
- Text Primary: `#1a1a2e` (near-black with blue cast)
- Text Secondary: `#6b6b80` (cool gray)
- Accent: `#ff4f00` (vivid orange)

**Fonts:** Space Grotesk (body) + Space Grotesk (headings, weight 700)

**Components:**
- Cards: white bg, no border, strong shadow, 12px radius
- Buttons: accent bg, white text, 8px radius, bold
- Inputs: `2px solid #e0e0e8`, strong focus state with accent border
- Shadows: `rgba(0,0,0,0.08) 0px 8px 24px`

**Layout:** Full-width hero with oversized typography. Asymmetric grid sections. Visual variety over uniformity.

## 5. Consumer App / Social

**Vibe:** Friendly, approachable, playful. Warm colors, rounded shapes.

**Palette:**
- Background: `#ffffff`
- Surface: `#fef7f0` (warm peach tint)
- Text Primary: `#2d2d2d` (soft black)
- Text Secondary: `#7a7a7a` (warm gray)
- Accent: `#ff5a5f` (coral red)

**Fonts:** Nunito (body) + Nunito (headings, weight 800)

**Components:**
- Cards: white bg, subtle shadow, 16px radius
- Buttons: accent bg, white text, 12px radius (rounded, not pill)
- Inputs: `1px solid #e0d8d0`, 12px radius, warm focus ring
- Shadows: `rgba(0,0,0,0.05) 0px 4px 12px`

**Layout:** Mobile-first single column. Large tap targets, generous spacing. Card-based content with varied sizes.

## 6. AI Platform (Claude-inspired)

**Vibe:** Warm, intellectual, editorial. Parchment tones with terracotta accent. Deliberately non-techy.

**Palette:**
- Background: `#f5f4ed` (parchment)
- Surface: `#faf9f5` (ivory)
- Text Primary: `#141413` (warm near-black)
- Text Secondary: `#5e5d59` (olive gray)
- Accent: `#c96442` (terracotta)

**Fonts:** Georgia or serif (headings, weight 500) + system sans-serif (body)

**Components:**
- Cards: ivory bg, `1px solid #e8e6dc` border, 12px radius
- Buttons: terracotta bg, ivory text, 12px radius
- Inputs: warm border, 12px radius, blue focus ring (only cool color)
- Shadows: ring shadows `0px 0px 0px 1px` instead of drop shadows

**Layout:** Centered content (max 1200px), generous vertical spacing (80-120px between sections). Alternating light/dark sections. Editorial feel with long-form readability.
