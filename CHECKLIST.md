# Sundai Project Pipeline Checklist

Use this checklist for each run.

- [ ] 1) Ideation: review latest approved Sundai projects + fresh web/news signals
- [ ] 2) Build MVP and create a **new** public GitHub repo
- [ ] 3) Push code and verify repo URL works
- [ ] 4) Create Sundai project (title + brief)
- [ ] 5) Add team member `vyahhi`
- [ ] 6) Fill edit page (GitHub URL, demo URL, one-liner, full description, start date)
- [ ] 7) Save + reload and verify fields persisted
- [ ] 8) Submit project and verify **Delist** state
- [ ] 9) Like (heart) your own published project
- [ ] 10) Deploy and verify live demo URL responds
- [ ] 11) Set/verify Demo URL on Sundai
- [ ] 12) Fill GitHub About (description + homepage=Sundai URL)
- [ ] 13) Update README with:
  - [ ] How to Run (from zero)
  - [ ] `Build on Sundai Club on <date>`
  - [ ] `Sundai Project: <url>` on separate rendered line
- [ ] 14) Commit and push final README changes
- [ ] 15) Mirror latest `skills/sundai-project-pipeline/SKILL.md` into this repo
